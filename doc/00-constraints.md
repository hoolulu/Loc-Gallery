# 00 — 硬性约束（实施前必读）

> **本文档优先级高于其他所有文档。** 与用户口头约定冲突时，以本文档为准。

---

## 1. 纯本地，禁止远程

| 规则 | 说明 |
|------|------|
| **禁止** `git push` / `git pull` / `git fetch` | 不与任何远程仓库通信 |
| **禁止** `gh` 命令 | 不创建 PR、不操作 GitHub |
| **禁止** 修改 `F:\Loc-Gallery` | 源项目只读参照，不得写入、不得提交 |
| **禁止** 在源项目目录执行 git 操作 | 避免影响原有项目 |
| **允许** 在 `F:\Loc-Gallery-Vue` 本地 `git init` + 本地 `commit` | 仅作本地版本快照，不推送 |
| **允许** 读取 `F:\Loc-Gallery` 源码 | 作为移植对照 |

### 目录隔离

```
F:\Loc-Gallery\          ← 源项目，只读，不动
F:\Loc-Gallery-Vue\      ← 重构项目，所有开发仅在此目录
```

### 端口隔离

```
F:\Loc-Gallery           → :3456（源项目，保持原样，只读对照）
F:\Loc-Gallery-Vue       → :3460（生产，restart.py）
                         → :3457（开发前端 Vite）
                         → :3458（开发后端 API）
```

两个项目可同时运行，互不占用端口。

## 2. 100% 功能完整移植

| 规则 | 说明 |
|------|------|
| **交付标准** | `06-feature-checklist.md` **全部 124 项**勾选通过（112 功能 + 12 数据复用） |
| **不分级交付** | 不存在「P0 过了就能交」的说法 |
| **P0/P1/P2 标签** | 仅表示实施优先顺序，**不是**可跳过项 |
| **源项目基线** | 8.1.0 全部功能，一项不漏 |
| **未通过** | 继续修复，直到 112/112 |

### 什么叫「移植完成」

1. 112 项功能清单全部 ✅
2. 数据复用验收 12/12 通过（见 `11-data-migration.md`）
3. 自动化测试全部通过（能跑的）
4. 手动冒烟 10 项全部通过
5. 本地 `restart.py` 一键启动正常
6. **开箱即用**：视频库、缩略图、收藏、历史、专辑与源项目一致，无需重新配置
7. **用户确认**后，才考虑是否发布到新仓库

## 3. 发布策略

```
阶段 1：本地开发 + 本地测试     ← 当前
阶段 2：用户验收确认            ← 你点头
阶段 3：（可选）发布到新仓库      ← 你决定，Agent 不主动做
```

**Agent 永远停留在阶段 1**，除非你明确要求进入阶段 3。
